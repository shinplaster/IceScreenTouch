# IceScreen Touch の使い方

[English](USER-GUIDE.md)

IceScreen Touch は、PC に映した iPhone の画面（ミラー画面）をマウスとキーボードで操作するためのソフトです。PC が Bluetooth のタッチ入力機器とキーボードのふりをして、ミラー画面の上のクリックやドラッグを iPhone へのタッチとして、打ったキーを iPhone のキーボード入力として送ります。

**IceScreen Touch は映像を受信しません。** iPhone の画面を PC に映すには、AirPlay の受信ソフトが別に必要です（[受信ソフトを入れる](#受信ソフトを入れる)を見てください）。IceScreen Touch はそのソフトのウィンドウを追います。

## 必要なもの

| もの | 条件 |
|---|---|
| PC | Windows 10（2004 以降）または Windows 11、64 ビット |
| Bluetooth | BLE の「ペリフェラル（周辺機器の役）」になれるアダプタ。IceScreen Touch の「状態」タブの準備の手順で確かめられます |
| iPhone / iPad | iPhone（iOS 26）と iPad Air（iPadOS 18）で確認しています。PC と同じネットワーク（Wi-Fi）につなぎます |
| 受信ソフト | AirPlay を受信して PC に映すソフト。5KPlayer、AirServer、LonelyScreen、Reflector 4、UxPlay で確認しています（それぞれの入れ方は[受信ソフトを入れる](#受信ソフトを入れる)にあります）。ほかのソフトもプロセス名を指定すれば追えますが、今のところ未確認のため、サポートの対象外です。受信ソフトは 1 つだけ起動してください。2 つ以上動いていると、iPhone の一覧に出ない項目があったり、iPhone の画面がもう一方に映ったりすることがあります |

.NET などを別に入れる必要はありません。

## インストール

IceScreen Touch は Microsoft Store から入れます。Store のバージョンには署名があり、自動で更新されます。

Store のバージョンには、24 時間の無料の試用期間があります。お使いの PC の Bluetooth で使えるかどうかを、試せます。残りの時間は「状態」タブに出ます。試用期間が終わると、Store で購入するまで使えなくなります。「状態」タブの「購入」ボタンで購入すると、すぐに使えるようになります。

ソースコードから自分でビルドすることもできます（GitHub のリポジトリの README を参照）。自分でビルドしたものは `IceScreenTouch.exe` 1 つで、コード署名がありません。

- 初めて開くと、「Windows によって PC が保護されました」と表示されることがあります。そのときは「詳細情報」を押し、「実行」を押してください。
- Windows 11 の **Smart App Control（スマート アプリ コントロール）がオン**の PC では、署名のないソフトは起動できません（「Windows セキュリティ > アプリとブラウザーの制御 > スマート アプリ コントロール」で確かめられます）。
- 会社の PC では、管理者の設定で起動できないことがあります。

Store のバージョンと自分でビルドしたものは、設定の保存場所が別です。

## 受信ソフトを入れる

IceScreen Touch は映像を受信しません。iPhone の画面を PC に映すのは、別のソフト（AirPlay の受信ソフト）です。IceScreen Touch はそのウィンドウを追います。次の「はじめての設定」の前に、受信ソフトを 1 つ入れてください。

**この一覧について**

- IceScreen Touch は、これらのソフトの開発元とは一切関係がありません。開発元から、紹介料などの金銭も一切受け取っていません。
- 一覧は名前順です。順序に優劣はありません。
- リンクは、各開発元の公式サイトだけです。料金や条件は、2026 年 11 月に公式サイトに表示されていたものです。変わることがあるので、ダウンロードや購入の前に、公式サイトで確かめてください。
- どれも別の製品で、それぞれの使用許諾、条件、サポートがあります。名前は、それぞれの所有者の商標です。
- Windows 11 と iPhone 15 Pro で確認しました。ほかの環境は確認していません。

**どのソフトにも共通すること**

- 受信ソフトは **1 つだけ**起動してください。複数を同時に起動すると、互いに邪魔をすることがあり、動作は保証できません。確認では、UxPlay を LonelyScreen と Reflector 4 と同時に動かすと、iPhone の画面ミラーリングの一覧には「LonelyScreen」とこの PC の名前だけが出て、UxPlay の名前が出ませんでした。ほかの 2 つを閉じると出ました。
- iPhone と PC は、同じネットワークにつなぎます。
- 受信ソフトごとに、iPhone の一覧（コントロールセンター > 画面ミラーリング）に出る名前が違います。下のそれぞれの項に書いてあります。
- IceScreen Touch の「状態」タブの「この PC の受信ソフト（AirPlay）」に、この PC にある受信ソフトが並びます。通常のフォルダに入っているものと、動いているものです。「起動」で起動し、「使う」を押すと、IceScreen Touch がそのソフトを追うようになります（IceScreen Touch はセッションを始め直します）。一覧は自動で探し直します。「探し直す」でも探せます。ほかのフォルダに入れたソフトは、動いているあいだだけ一覧に出ます。
- Microsoft Store から入れた AirServer を追えるのは、IceScreen Touch **0.2.0 以降**だけです。0.2.0 から、5KPlayer と Reflector 4 は受信ソフトの一覧に出て、映像の上のドラッグでウィンドウが動かなくなります。

**一覧**

| 受信ソフト | 料金（公式サイト、2026 年 11 月） | 試用 | 入れ方 | 備考 |
|---|---|---|---|---|
| 5KPlayer | 無料 | なし（無料） | 公式サイトのインストーラー | 起動時に無料登録の画面が出ます。登録しなくてもミラーリングできました（画面は閉じました） |
| AirServer | 1 台 19.99 ドル（個人向けのライセンス） | Microsoft Store から入れたものは、初回の起動で「Your AirServer trial will expire in 31 days」と出ます | Microsoft Store、または winget | 入れ方が 2 通りあります。IceScreen Touch では、どちらも 1 つの「AirServer」として並びます |
| LonelyScreen | 年 19.95 ドル（Personal Use、年額のサブスクリプション） | 無料で試せるものをダウンロードできます | 公式サイトの小さなダウンローダー | 初回の起動でファイアウォールの確認が出ます |
| Reflector 4 | 公式の製品ページには出ていません | 7 日間。購入するまで映像に「TRIAL MODE」の透かしが入ります | 公式サイトのインストーラー、または winget | 「Show Frame」を一度オフにします（下の項） |
| UxPlay | 無料（オープンソース、GPLv3） | なし | ソースコードから自分でビルド | 自分でビルドできる人向け |

### 5KPlayer

- 開発元: DearMob / Digiarty
- 公式サイト: <https://www.5kplayer.com/>
- 料金: 無料
- 試用: なし
- 確認したバージョン: 6.11

1. Windows のダウンロードページ <https://www.5kplayer.com/5kplayer-download-windows.htm> を開き、インストーラー（`5kplayer-64bit.exe`。署名は Digiarty Software, Inc.）をダウンロードして実行します。
2. 初回の起動で、5KPlayer が「無料登録」の画面を出します。国、名前、メールアドレスを求められますが、登録しなくてもミラーリングできました。画面は閉じてかまいません。
3. iPhone の画面ミラーリングの一覧には、「5KPlayer-」の後に PC の名前が付いた名前で出ます。
4. IceScreen Touch の「状態」タブの一覧に「5KPlayer」が出ます。「起動」で 5KPlayer を起動します。映像を映すのは別のプログラム `Airplay.exe` で、5KPlayer が起動します（5KPlayer を閉じると終わります）。ミラーリングを始めるとミラー画面が開き、止めると閉じます。「使う」を押します。
5. ミラー画面にはタイトルバーがありません。IceScreen Touch で操作中は、映像をドラッグしてもウィンドウは動きません。IceScreen Touch がドラッグを iPhone に送るので、スワイプできます。ウィンドウを動かしたいときは、**Alt** を押しながらドラッグします。

### AirServer

- 開発元: App Dynamic
- 公式サイト: <https://www.airserver.com/>
- 料金: 1 台 19.99 ドル（個人向けのライセンス: <https://airserver.com/Buy/Consumer>）
- 試用: Microsoft Store から入れたものは、初回の起動の試用の画面に「Your AirServer trial will expire in 31 days」と「Continue Trial」のボタンが出ます
- 確認したバージョン: Microsoft Store から入れたもの: 2025.2.20、インストーラーで入れたもの（AirServer Universal）: 5.7.2

1. 入れ方は 2 通りあります。どちらも確認しました。
   - **Microsoft Store から入れる**: 「AirServer Windows Desktop Edition」を探します（Store の製品 ID は 9NBLGGH52639）。公式のダウンロードページ <https://www.airserver.com/download> は、Windows 10 の利用者を Microsoft Store に案内しています。この入れ方は IceScreen Touch 0.2.0 以降が必要です。
   - **インストーラーで入れる**（AirServer Universal）: `winget install --id AppDynamic.AirServer -e` で入れます。
2. 初回の起動で、Microsoft Store から入れたものは、「Continue Trial」のボタンがある試用の画面を出します。試すときは、このボタンを押します。
3. iPhone の画面ミラーリングの一覧には、PC の名前で出ます。
4. IceScreen Touch では、どちらで入れても「AirServer」の 1 行にまとまります。「使う」を押します。

### LonelyScreen

- 開発元: IMTIGER Technologies
- 公式サイト: <https://www.lonelyscreen.com/>
- 料金: 年 19.95 ドル（Personal Use、年額のサブスクリプション）
- 試用: <https://www.lonelyscreen.com/download.html> から無料で試せるものをダウンロードできます
- 確認したバージョン: 1.2.16

1. ダウンロードページから `lonelyscreen-win-installer.exe`（小さなダウンローダー）をダウンロードして実行します。LonelyScreen は `C:\Program Files (x86)\LonelyScreen` に入ります。
2. 初回の起動で、Windows がファイアウォールの「アクセスを許可しますか」という確認を出します。許可してください。
3. iPhone の画面ミラーリングの一覧には、「LonelyScreen」で出ます。
4. IceScreen Touch の「状態」タブの一覧に「LonelyScreen」が出ます。「起動」を押し、次に「使う」を押します。
5. LonelyScreen の 2 つの表示（ちらつきと「ファイアウォールで止められている」）は、「[困ったとき](#困ったとき)」にあります。

### Reflector 4

- 開発元: Squirrels
- 公式サイト: <https://www.airsquirrels.com/reflector>
- 料金: 公式の製品ページには出ていません
- 試用: 7 日間。購入するまで映像に「TRIAL MODE」の透かしが入ります。<https://www.airsquirrels.com/reflector/try> から入手します
- 確認したバージョン: 4.1.3

1. 試用のページから試せるものをダウンロードして、インストーラーを実行します。`winget install --id Squirrels.Reflector.4 -e` でも入れられます。
2. インストーラーが自分でファイアウォールの規則を作ります。初回の起動で確認は出ませんでした。
3. iPhone の画面ミラーリングの一覧には、PC の名前で出ます。
4. IceScreen Touch の「状態」タブの一覧に「Reflector 4」が出ます。「起動」を押し、次に「使う」を押します。ミラー画面は別のウィンドウで開き（タイトルは「Reflector 4 - 」の後に端末の名前）、ミラーリングを止めると閉じます。
5. **端末のフレームを一度オフにします。** Reflector 4 は、既定では映像の周りに端末のフレームを描きます。フレームがあると、IceScreen Touch はフレームまで映像として扱うので、タッチの位置がずれることがあります。ミラーリング中に、ミラー画面の下のバーにある歯車のアイコン（または小さな Reflector のウィンドウの、端末の行のドロップダウン）から設定を開き、「Frame」で「Show Frame」のチェックを外します。この設定は保存されます。
6. Reflector 4 は、ミラー画面をドラッグするとウィンドウが動く作りです。IceScreen Touch（0.2.0 以降）は、映像の上のドラッグを Reflector 4 に渡さずに iPhone に送るので、ウィンドウは動かず、スワイプできます。ウィンドウを動かしたいときは、**Alt** を押しながらドラッグします。

### UxPlay（自分でビルドできる人向け）

- 開発元: UxPlay のプロジェクト（オープンソース、GPLv3）
- 公式サイト: <https://github.com/FDH2/UxPlay>
- 料金: 無料
- 試用: なし
- 確認したバージョン: コミット `b1be2bd`（UxPlay 1.74）のソース

1. UxPlay は、ソースコードから自分でビルドします。手順は[Windows で UxPlay をビルドする](BUILD-UXPLAY.ja.md)にあります。
2. 初回の起動で、Windows が `uxplay.exe` のファイアウォールの確認を出します。許可してください。許可しないと、Windows がブロックの規則を作り、iPhone から接続できません。
3. iPhone の画面ミラーリングの一覧には、IceScreen Touch の「設定」タブの **AirPlay の名前**で出ます（既定は「IceScreen Touch」）。
4. IceScreen Touch が UxPlay を起動することもできます。「設定」タブで「UxPlay を起動する」を選び、`uxplay.exe` の場所を指定します（詳しくはビルドの手順に書いてあります）。このとき、遅延を小さくするデコーダーのオプションは自動で付きます。

## はじめての設定

1. 受信ソフトを入れて起動します（[受信ソフトを入れる](#受信ソフトを入れる)を見てください）。起動するのは 1 つだけにします。
2. IceScreen Touch を起動します。「状態」タブの上に今の状態（「操作できます」「iPhone の接続を待っています」など）と次にやることが、その下に番号付きの「準備」の手順が出ます。緑の印が付くまで、上から順に進めてください。この PC で見つかった受信ソフトは「この PC の受信ソフト（AirPlay）」に並びます（受信ソフトの対応が要るときは自動で開きます）。入れた受信ソフトの「使う」を押します。
3. **Bluetooth の接続**: iPhone の「設定 > Bluetooth」で、この PC の名前を選びます。初回はペアリングの確認が出ます。2 回目からは自動で接続します。一覧にこの PC の名前が 2 つ出ることがあります。片方だけではタッチが届かないので、両方を選んでペアリングしてください。
4. **ズーム**: iPhone の「設定 > アクセシビリティ > ズーム」をオンにします（拡大はしなくてかまいません）。**これがオフだとタッチが届きません。**
5. **画面ミラーリング**: iPhone のコントロールセンターを開き、「画面ミラーリング」で受信ソフトの項目を選びます（受信ソフトごとに出る名前は、上のそれぞれの項に書いてあります）。
6. ミラー画面をクリックして、iPhone が反応すれば完了です。

うまく届かないときは、「検証」タブの「タッチを検証」で確かめられます（ズームの手順にあるボタンからも開けます）。先にボタンを押し、表示された URL を iPhone の Safari で開きます。

**画面の形**（iPhone、ホームボタン付きの iPhone、iPad）は、端末が Bluetooth で知らせる機種から判別します（「設定」タブの「ミラーリングする端末の画面」の既定は「自動」）。AirServer や LonelyScreen のように映像のサイズを知らせない受信ソフトでは、この形で映像の位置を探します。IceScreen Touch が知らない機種で位置がずれるときは、そこで形を選んでください。

**複数の端末がつながっているとき**（iPhone と iPad など）は、タッチとキーは 1 台にだけ届きます。送り先は、ミラー画面に映っている端末です。それが分からないときは、最後につながった端末です。「状態」タブの「操作の送り先」に、どの端末へ送っているかとその理由が出ます。そこで端末を選ぶこともできます（「自動」で元に戻ります）。映っている端末は名前で見分けます。英字も数字も含まない名前（すべて日本語など）は、IceScreen Touch が UxPlay を起動するときにしか見分けられません。

## 操作

| 操作 | iPhone での動き |
|---|---|
| 左クリック・ドラッグ | タップ・スワイプ（1 本指） |
| Ctrl + 左ドラッグ | ピンチ（2 本目の指は画面の中心に対称） |
| Alt + クリック・ドラッグ | iPhone には送らず、受信ソフトに渡す（ウィンドウの移動など）。どの受信ソフトでも同じ（IceScreen Touch 0.2.0 以降） |
| 右クリック | 長押し（そのままドラッグもできます） |
| ホイール | スクロール（Shift で横） |
| Home キー | ホーム（ホームボタンのキーを送ります） |
| Ctrl + R | 端末の画面を回転してタッチの位置が反転してしまった場合に押してください（横向きは 90° ⇄ 270°、縦向きは 0° ⇄ 180°） |
| そのほかのキー | iPhone で文字入力（次の節） |

キーは、ミラー画面のウィンドウが前面にあるときだけ効きます。iPhone を横向きにしたとき、2 つの横向きのどちらかは自動では分かりません。タッチの位置が反対になったら Ctrl + R（または「状態」タブの「回転を切り替え」）を押してください。iPad を上下逆の縦向きにしたときも、タッチ位置が反転します。縦向きで押すと 0° ⇄ 180° が切り替わります（180° は保存しません。開始し直すと 0° に戻ります）。

Reflector 4 と 5KPlayer は、映像をドラッグするとウィンドウが動きます。IceScreen Touch はそのドラッグを iPhone に送ります。この 2 つのウィンドウを動かすときは、Alt を押しながらドラッグしてください。

## 文字入力

ミラー画面が前面にあるとき、PC で打ったキーは iPhone に届きます（iPhone からは Bluetooth のキーボードに見えます）。iPhone の入力欄をクリックしてから打ってください。画面のキーボードは出たままで、指でも打てます。

| PC のキー | iPhone での動き |
|---|---|
| 英数字・記号・Enter・Backspace・Tab・Esc・矢印・Delete | そのまま |
| Ctrl + キー | ⌘ + キー（Ctrl+A で全選択、Ctrl+C / Ctrl+V でコピー／ペースト、Ctrl+Z で取り消し） |
| Ctrl + Space、半角/全角 | 入力の切り替え（英語 ⇄ 日本語） |
| Alt や Windows キーとの組み合わせ、F1〜F12、音量などのキー | iPhone には送らず、Windows がそのまま使います（Alt+Tab など） |

- **日本語の入力**: iPhone の「設定 > 一般 > キーボード > キーボード」に「**日本語 - ローマ字**」を追加してください（「日本語 - かな」だけでは、PC のキーで打つと英字のままです）。Ctrl+Space で日本語に切り替え、ローマ字で打ち、Space で変換、Enter で確定します。変換は iPhone 側で行います。切り替えは追加したキーボードの順に回るので、日本語にならないときはもう一度 Ctrl+Space を押してください。
- **記号の位置**: PC のキーボードが US でも JIS でも、PC で打った記号がそのまま入ります（IceScreen Touch は US 配列のキーボードとしてキーを送ります）。
- **iPad の「フルキーボードアクセス」**: オンのあいだは Space と矢印キーが効きません（iPad が自分の操作に使います）。「設定 > アクセシビリティ > キーボード」でオフにしてください。
- **ほかのアプリで打つとき**: キーを送るのはミラー画面が前面にあるときだけです。キーを送りたくないときは、「設定」タブの「ミラー画面で打ったキーを端末に送る」をオフにします（Home キーと Ctrl+R は効いたままです）。

## 検証タブ

iPhone の Safari に計測ページを開いて、次のことを測れます。**先にボタンを押してください**（ボタンを押してから計測が終わるまでの間だけ、ページが開けます）。ボタンを押すと、ページが開かれるまでの間、そのページの **QR コード**が出ます。iPhone のカメラで読み取り、出てきたリンクをタップすると Safari で開けます（URL を打つ必要はありません）。iPhone がページを開くには、ページのポート（TCP 8000）を受け付ける必要があります。Store のバージョンは、インストールのときにこれを済ませます。自分でビルドした場合は、「ファイアウォールを設定（管理者）」を一度押してください。ポートを同じネットワークからだけ受け付けるようにします（Windows の確認が出ます）。

- **タッチを検証**: 9 点のタップ、スワイプ、ピンチが iPhone の画面に 1:1 で届くか。
- **スクロールを計測**: ホイールのスクロールの量と流れ方。
- **遅延を計測**: 押してから PC の画面に反応が映るまでの時間。iPhone のタッチの分と映像の分に分けて表示します。測っている間は、ミラー画面を他のウィンドウで隠さないでください。
- **キー入力を検証**: ページの入力欄に、英数字・記号・Enter・矢印・Backspace・⌘A / ⌘C / ⌘V を打ち、そのとおりに入るか。ページを開いたら**入力欄をタップしてカーソルを置いてください**（置くと始まります）。iPhone の入力は英語にしておきます。記号だけが JIS の配列のように入ったときは、端末のハードウェアキーボードの配列を QWERTY（US）にするよう案内します。Space と矢印だけが届かないときは、フルキーボードアクセスをオフにするよう案内します。日本語の変換は検証しません。

## 設定とログ

- 設定: データのフォルダの `settings.json`（「設定」タブで変えられます）。データのフォルダは、自分でビルドした場合は `%LOCALAPPDATA%\IceScreenTouch` です。Store のバージョンでは、パッケージのフォルダの中にあります。「情報」タブにフォルダが表示され、そこから開けます。
- 画面の言語: Windows の表示言語に合わせます（日本語のときは日本語、ほかは英語）。「設定」タブの「言語（Language）」で English か日本語を選ぶこともできます。選び直した言語は、次に IceScreen Touch を起動したときから使われます。
- 画面の色: Windows のアプリ モード（ライト／ダーク）に合わせます。「設定」タブの「画面の色（ライト／ダーク）」でライトかダークを選ぶこともできます。「保存して適用」を押すとすぐに変わります。
- ログ: データのフォルダの `logs\`（「ログ」タブの「ログのフォルダを開く」）
- バージョンとライセンス: 「情報」タブ（バージョン、ライセンス、第三者のソフトウェア、データのフォルダ）。問題を報告するときは、「バージョン情報をコピー」で写した文を貼ってください。
- 環境変数 `ICESCREENTOUCH_DATA_DIR` を設定すると、設定とログの場所を変えられます。

## 困ったとき

| 症状 | 確かめること |
|---|---|
| 「Bluetooth アダプタ」が赤い | アダプタが BLE のペリフェラルに対応していません。対応する USB アダプタが必要です |
| iPhone の Bluetooth に PC が出ない | IceScreen Touch が動いているか。ほかに BLE の HID を公開するソフト（古い IceScreen Touch など）が動いていないか |
| クリックしても iPhone が反応しない | iPhone のズームがオンか。「状態」タブの手順 2「iPhone と接続（Bluetooth）」に緑の印が付いているか |
| 位置がずれる | 受信ソフトが映像の周りに余白を付けている場合、「設定」タブの「映像の位置をウィンドウの中から探す」をオンにします。同じタブの「ミラーリングする端末の画面」も確かめてください |
| 別の端末が反応する | 「状態」タブの「操作の送り先」を確かめ、必要ならそこで端末を選びます |
| Space と矢印キーが効かない（iPad） | 「設定 > アクセシビリティ > キーボード」の「フルキーボードアクセス」をオフにします |
| 上下逆の iPad でタッチが反対になる | 縦向きのまま Ctrl + R（または「回転を切り替え」）を押します |
| ミラー画面がちらつく | IceScreen Touch は受信ソフトのウィンドウをときどき読み取ります。ほかのウィンドウが一部を隠していると、ちらつく受信ソフト（LonelyScreen）があります。ミラー画面を隠さないでください |
| LonelyScreen が「ファイアウォールで止められている」と出す | ミラーリングできていれば問題ありません。ファイアウォールの規則を同じネットワークに限ったときにも、LonelyScreen はこう表示します |
| 以前は動いたのに接続しなくなった | iPhone の「設定 > Bluetooth」でこの PC の登録を解除し、ペアリングし直します |
| バージョンを上げたらタッチもホームも効かない | IceScreen Touch のバージョンによって、iPhone に見せる入力機器の構成が変わることがあります（0.1.0 の途中でホームキーとキーボードを足しました）。iPhone でこの PC の登録を解除してペアリングし直してください。それでも直らないときは、Windows の「設定 > Bluetooth とデバイス」でも iPhone を削除してから、もう一度ペアリングします |
| 受信ソフトが iPhone の画面ミラーリングの一覧に出ない | 受信ソフトが動いているか、動いているのはその 1 つだけか。複数の受信ソフトが動いていると、出ない項目があります（確認では、LonelyScreen と Reflector 4 が動いているあいだ UxPlay の名前が出ず、2 つを閉じると出ました）。iPhone と PC が同じネットワークにつながっているか。Windows がファイアウォールの許可を求めたときに、許可したか（UxPlay は、許可しないとブロックの規則ができて iPhone から接続できません。[Windows で UxPlay をビルドする](BUILD-UXPLAY.ja.md)を見てください） |
| クリックした位置とタッチの位置がずれる（Reflector 4） | Reflector 4 は既定で映像の周りに端末のフレームを描き、フレームがあるとタッチの位置がずれることがあります。設定で「Show Frame」をオフにします（[Reflector 4](#reflector-4) を見てください） |
| 映像をドラッグしても受信ソフトのウィンドウを動かせない（Reflector 4、5KPlayer） | **Alt** を押しながらドラッグします。Alt なしのドラッグは iPhone に送られます |
| 「状態」タブに「機器はつながっていますが、ウィンドウが見つかりません」と出る | ミラー画面のウィンドウが最小化されていないか確かめます。この表示は IceScreen Touch 0.2.0 以降のものです |
