# IceScreen Touch プライバシー ポリシー

[English](PRIVACY.md)

施行日: 2026-11-08

このポリシーは IceScreen Touch（以下「本アプリ」）に適用されます。Microsoft Store のバージョンにも、GitHub のソースコードから自分でビルドしたものにも当てはまります。どちらも同じソースコードから作られ、データの扱いも同じです。

## 要点

- 本アプリは、開発者にも、そのほかの第三者にも、データを送りません。アカウント、広告、利用状況の分析、クラッシュ レポート、更新の確認はありません。
- 本アプリがあなたの入力で行うことは、PC とあなた自身の iPhone / iPad のあいだ（Bluetooth とローカル ネットワーク）で完結します。
- 本アプリは、小さな設定ファイルとログ ファイルを PC に残します。どこにもアップロードされません。いつでも削除できます。
- Microsoft Store のバージョンは、ライセンス（試用版か購入済みか）を Windows にたずねます。「ほかのソフトとサービス」を見てください。自分でビルドしたものは、たずねません。

## 本アプリがすること

IceScreen Touch は、PC に映した iPhone / iPad の画面（ミラー画面）を、PC のマウスとキーボードで操作するためのソフトです。ミラー画面は、PC 上の別の AirPlay 受信ソフトが映します。IceScreen Touch はその受信ソフトのウィンドウを追い、ミラー画面の上のマウスのクリック、ホイール、キーを Bluetooth のタッチ入力とキーボード入力に変えます。PC が Bluetooth の入力機器のふりをして、これらをあなたの端末へ送ります。

## PC に保存されるもの

本アプリがあなたのデータを書き込むのは、専用のデータ フォルダー `%LOCALAPPDATA%\IceScreenTouch` だけです（「情報」タブにこのフォルダーが表示され、開くボタンもあります）。環境変数 `ICESCREENTOUCH_DATA_DIR` を設定していると、そのフォルダーを使います。Microsoft Store のバージョンでは、Windows がこのフォルダーをパッケージ専用の保存場所（`%LOCALAPPDATA%\Packages\<パッケージ ファミリー名>\` の下）に振り替えることがあります。

| ファイル | 内容 |
|---|---|
| `settings.json` | 設定: 本アプリが AirPlay で名乗る名前、使う受信ソフトとそのファイルの場所、画面の形、回転、スクロールや長押しの設定、キーを送るかどうか、言語とテーマ、本アプリのウィンドウの位置、そのほかの技術的な設定。「状態」タブで操作の送り先の端末を選んだときは、その端末の Bluetooth の識別子と Bluetooth の名前（たとえば「太郎の iPhone」）も入ります。 |
| `logs\IceScreenTouch-<日付>-<時刻>.log` | 診断用のログ。起動 1 回につき 1 ファイルです。新しい 10 個を残し、古いものは削除します。 |
| `logs\uxplay-<日付>-<時刻>.log` | 詳細ログをオンにして、本アプリが UxPlay を自分で起動したときだけ: UxPlay の出力。新しい 10 個を残します。 |

データ フォルダーのほかに、次のものが Windows の一時フォルダーを使いますが、あなたのデータは入りません。どちらのビルドでも、最初に起動したとき、.NET が本アプリのネイティブ ライブラリー（画面と文字の描画用）を `%TEMP%\.net` に展開します。診断用のスイッチ `--self-check`（ターミナルから実行するもので、本アプリが自分で使うことはありません）は、試験用のファイルのために一時フォルダーを作り、終わると削除します。

自分でビルドしたもの（Store のビルドではない方）では、テスト ページのためのファイアウォールの設定（後述）をするあいだ、Windows の一時フォルダーに短い一時ファイルを作り、設定が終わると削除します。Store のビルドはこれをしません。

### ログに入るもの

ログは問題を調べるためのものです。時刻、本アプリのバージョン、本アプリが何をしているかが入ります。ほかに次のものが入ることがあります。

- 見つけた、または起動した受信ソフトと、本アプリのログ ファイルの名前と場所（場所には Windows のユーザー名が含まれることがあります）
- PC につながった端末の Bluetooth の名前と機種番号（`iPhone16,1` など）。Bluetooth の機器 ID そのものは書かず、元に戻せない短い符号に置き換えます。
- 受信ソフトにつながった端末のローカル ネットワークのアドレス（IP アドレス）とホスト名、およびテスト ページのアドレスに含まれる PC 自身のローカルのアドレス
- 本アプリが UxPlay を起動したときに、UxPlay が知らせる端末の名前と機種
- PC が Bluetooth のペリフェラルになれないときの、PC の Bluetooth アダプターのアドレス
- Store のバージョンでは、ライセンスの種類（試用版か購入済みか）と試用期間の終わりの時刻（変わるたびに）

ログには、あなたが打ったキー（詳細ログでも、押されているキーの「数」だけで、どのキーかは書きません）、クリックやタッチの位置、画面の画像は**入りません**。

ログを不具合の報告に添付するときは、先に中身を確かめてください。既定ではオフの詳細な UxPlay のログには、接続について UxPlay が出力する内容（端末の名前、OS のビルド、ネットワークのアドレスなど）も入ります。UxPlay が出力するハードウェア ID 風の識別子とセッションの鍵は本アプリが取り除きますが、すべてではありません。

### 保存期間

設定は、あなたが削除するまで残ります。ログは各種類で新しい 10 ファイルまでです（上記）。それ以外は保存しません。タッチ、キー入力、画面の画像はメモリー上で処理され、保存されません。

## キーボードとマウスの入力

動作のために、本アプリはセッションが動いているあいだ（本アプリの起動から、「停止」を押すか終了するまで）、Windows の低レベルのフック（キーボードとマウス）を 2 つ入れます。フックを使うと、プログラムは他のプログラムに向かう入力イベントを見ることができます。本アプリは次の目的にだけ使います。

- **キーボード**: フックには PC のすべてのキーの押下と解放が通知されます。本アプリがキーを処理するのは、ミラー画面のウィンドウが最前面のときだけです。そのとき、キーを Bluetooth であなたが選んだ端末へ送り、そのキーは Windows には渡りません（Alt や Windows キーとの組み合わせ、ファンクション キー、メディア キーは Windows に残します）。ほかのウィンドウが最前面のときは、Home と回転のショートカットのために「どのキーが押されているか」を覚えるだけ（保存もログもしません）で、すべてのキーをそのまま通します。「設定」タブの「ミラー画面で打ったキーを端末に送る」をオフにすると、キーは端末へ送りません（ミラー画面での Home と回転のショートカットだけは使えます）。
- **マウス**: フックには左右のボタンの押下と解放、ホイールの回転が通知されます。本アプリが使うのは、見えているミラー画面の映像の上のイベントだけで、ほかは保持せずに無視します。マウスの入力を止めたり変えたりはせず、マウスの移動そのものもフックでは追いません。

ミラー画面で打った内容は、パスワードも含めて、操作の送り先として選ばれた 1 台の端末へ Bluetooth で送られ、本アプリには保存されません。送るのは、PC とペアリングし、暗号化された接続で購読している端末だけです。PC とペアリングするのはご自身の端末だけにし、送り先は「状態」タブで確かめてください。

セッションは「停止」ボタン（またはトレイのメニュー）で止められ、2 つのフックが外れて Bluetooth の入力機器としての動作も止まります。トレイのメニューの「終了」で本アプリを終了できます。ウィンドウを閉じただけでは通知領域に隠れるだけで（設定で変えられ、既定はそうなります）、セッションは動き続けます。

## 画面の内容

受信ソフトのウィンドウの中で映像の位置を探すために、本アプリはそのウィンドウの画素を画面から読みます。遅延の検証では、画面の小さな四角の明るさを読みます。これらの画素はメモリー上で調べて捨てます。保存も録画もせず、どこにも送りません。本アプリは画面を録画したり、スクリーンショットを撮ったり、ほかのウィンドウの中身を見たりしません。

## Bluetooth

- 本アプリのセッションが動いているあいだ（本アプリの起動から、「停止」を押すか終了するまで）、PC は Bluetooth Low Energy の入力機器（タッチ、マウス、ホームキー、キーボード）として振る舞います。近くの端末の Bluetooth の一覧に表示されます。タッチやキーの入力を受け取れるのは、PC とペアリングした端末（暗号化された接続）だけです。ペアリングには、端末と PC の両方での承認が要ります。本アプリは、入力を操作の送り先の 1 台（「状態」タブ）にだけ送ります。
- 本アプリは、デバイス情報として製造元の名前「IceScreen Touch」と、固定の電池残量を知らせます。あなたの名前や PC のシリアル番号などは送りません。
- つながった iPhone / iPad から、Bluetooth の名前と機種番号（デバイス情報の標準の「Model Number」。`iPhone16,1` など）を読みます。どの端末かを見分け、画面の形を選ぶために使います。これらはメモリー上に置き、上記のとおりログに書きます。「状態」タブでその端末を選んだときは、名前が `settings.json` にも保存されます。
- ペアリングの情報そのものは、本アプリではなく Windows と端末が保存します。Windows の「設定 > Bluetooth とデバイス」と、端末の Bluetooth の設定で削除できます。

## ローカル ネットワーク

本アプリ自身はインターネットに接続しません（Store のバージョンのライセンスの確認は、「ほかのソフトとサービス」にあるとおり Windows を通して行われます）。ローカル ネットワークでは次のことをします。

- **受信ソフトが映している端末を調べる**: 受信ソフトにつながっているローカル ネットワーク上の端末を（システムの接続の一覧から）調べ、その端末にホスト名をたずねる小さな問い合わせ（mDNS）を、その端末へ直接送ります。たずねるのは、PC 自身のネットワークの中のアドレスだけです。
- **テスト ページ**: 「検証」のボタン（タッチ、スクロール、遅延、タイピング）を押すと、本アプリは PC の TCP ポート 8000 で小さな Web サーバーを起動します。検証が終わるまでのあいだだけ動きます。iPhone / iPad の Safari で開きます（本アプリが QR コードを出します）。ページは、測定のためにタッチやキーのイベントを PC へ返します。これらは検証のあいだメモリー上にあるだけで、保存されず、検証が終わると捨てられます。検証ごとに使い捨ての乱数の鍵を使い、その鍵で最初に送ってきた端末からの結果だけを受け付けます。iPhone がページに届くには、Windows ファイアウォールで TCP ポート 8000 を通す必要があります。ビルドによってやり方が違います。
  - **Store（MSIX）のビルド**: パッケージが TCP ポート 8000 の受信規則（すべてのネットワーク プロファイル、どのリモート アドレスからも）を宣言しており、アプリのインストール時に Windows が作り、アンインストール時に消します。アプリは規則の状態を表示するために読むだけで、変更はせず、このための一時ファイルも作りません。Web サーバーは検証が動いているあいだだけ待ち受け、検証ごとに URL の中の乱数の鍵が要り、その鍵つきで最初にイベントを送ってきた端末だけを受け付けます。
  - **自分でビルドしたもの**: 「検証」タブにそのためのボタンがあり、変更の前に Windows が管理者の許可を求めます。規則はローカル サブネットだけを通し、アプリは上で述べた短い一時ファイルを、実行のあいだだけ作ります。
- **受信ソフト**が映像を出します。次の項を見てください。

## ほかのソフトとサービス

- **AirPlay の受信ソフト**（5KPlayer、AirServer、LonelyScreen、Reflector 4、UxPlay など）は別の製品です。IceScreen Touch の一部ではなく、それぞれのプライバシー ポリシーとネットワークの使い方があります。IceScreen Touch は、あなたが頼んだときに受信ソフトを起動し、そのウィンドウを追います。受信ソフトが保存しているものは読みません。本アプリが UxPlay を自分で起動したときは、UxPlay は PC 上の子プロセスとして動き、その出力を IceScreen Touch が読みます（上記のログを見てください）。
- **iPhone / iPad と Apple**: 本アプリは Apple には接続しません。端末がタッチやキーをどう扱うかは、Apple の規約とポリシー、および端末の設定によります（たとえば、タッチが届くには「アクセシビリティ > ズーム」がオンである必要があります）。
- **リンク**: 「情報」タブには、プロジェクトの GitHub のページと問題報告のページをブラウザーで開くボタンがあります。押すまでは何もしません。開いたあとは GitHub のプライバシー ステートメントが適用されます。
- **Store のライセンス（Microsoft Store のバージョンのみ）**: Store のバージョンには無料の試用期間があり、Microsoft Store で購入できます。本アプリは、起動したときと、動いているあいだ約 10 分ごと（試用期間が終わったあとは 1 分ごと）に、Windows の Store サービスに、本アプリのライセンス（試用版か購入済みか）と試用期間の終わりをたずねます。これは Windows を通して Microsoft に届き、Microsoft がプライバシー ステートメントに従って扱います。本アプリ自身は個人データを送りません。ライセンスの種類と試用期間の終わりの時刻はログに書きますが、それ以外の場所にライセンスを保存することはありません。「購入」のボタンを押すと、購入は本アプリではなく Microsoft Store のダイアログで行われます。自分でビルドしたものは、これを一切行いません。
- **Microsoft Store と GitHub**: Microsoft Store から入手した場合、Microsoft は、ダウンロードやパッケージの利用についてのデータを、Microsoft 自身の規約に従って収集することがあり、開発者は Microsoft から集計された形で報告を受け取ることがあります。GitHub からソースコードをダウンロードした場合は、ダウンロードに GitHub の規約が適用されます。本アプリ自身は、どちらにも何も報告しません。

## データの削除

1. 本アプリを終了します（トレイのメニュー > 終了）。
2. アンインストールします（Windows の「設定 > アプリ」）。Microsoft Store のバージョンでは、データがパッケージ専用の保存場所にある場合、Windows がデータも一緒に削除することがあります。自分でビルドしたものは、exe を置いたフォルダーを削除します。
3. データ フォルダー `%LOCALAPPDATA%\IceScreenTouch` を削除します。Microsoft Store から入れたときは、`%LOCALAPPDATA%\Packages\<パッケージ ファミリー名>\LocalCache\Local\IceScreenTouch` にデータがあることもあります。残っていれば、それも削除します。以前のバージョン（旧名 iScrMirror）を使っていたときは、`%LOCALAPPDATA%\iScrMirror` があれば、それも削除します。
4. ペアリングも消したいときは、iPhone / iPad の Bluetooth の一覧と、Windows の「設定 > Bluetooth とデバイス」から、この PC を削除します。

本アプリは開発者に何も送らないので、開発者の手元に削除すべきデータはありません。

## このポリシーの変更

本アプリがデータの扱いを変えるときは、そのバージョンを出す前にこのポリシーを変更し、冒頭の日付を更新します。最新の文面は、プロジェクトのリポジトリー（`docs/PRIVACY.ja.md`）と、Store バージョンについては Store のページにあります。
